# TripNest — Travel Planning Platform

## Project Overview
TripNest is a fictional travel planning platform that helps users discover destinations, explore travel packages, and plan memorable trips.

## Objective
To create a modern, responsive travel landing page using Figma UI/UX design principles.

## Target Audience
- College students
- Young professionals
- Couples and families
- Budget-conscious travelers

## Main Features
- Responsive navigation header
- Hero section with call-to-action buttons
- Destination search section
- Popular destination cards
- Three or more feature cards
- Travel package cards
- Testimonials section
- Footer with navigation and social links

## Design System
- Primary purple: #6C5CE7
- Secondary blue: #4F7DF3
- Accent coral: #FF7A59
- Background: #FFFFFF
- Typography: Inter

## UI/UX Concepts
- Figma Auto Layout
- Reusable components
- Shared color and typography styles
- Responsive desktop, tablet, and mobile layouts
